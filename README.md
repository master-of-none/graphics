# Graphics

A collection of graphics programming projects and experiments written primarily in modern C++.

This repository is dedicated to exploring the mathematics, algorithms, and systems behind computer graphics. The goal is to understand how rendering works by implementing its fundamental components from scratch, with an emphasis on correctness, performance, and low-level programming.

## Projects

### 1. Ray Tracer
**Status:** In Progress

A CPU-based ray tracer built from scratch in C++.

The project explores the fundamentals of physically based rendering, including:

- Ray generation and geometric intersections
- Camera models and image generation
- Surface normals and material systems
- Reflection and refraction
- Monte Carlo sampling and antialiasing
- Bounding Volume Hierarchies (BVH)
- Multithreaded rendering
- Performance profiling and optimization

Future experiments may include GPU acceleration using CUDA.

### 2. More to Come

Future projects may explore:

- Software rasterization
- Computational geometry
- Shading and lighting models
- Procedural graphics
- GPU programming and parallel rendering
- Real-time rendering techniques

## Tech Stack

- **Language:** C++20
- **Build System:** CMake
- **Platforms:** Linux, macOS
- **GPU Computing:** CUDA (planned)

## Philosophy

The emphasis is on understanding rather than abstraction.

Where practical, core algorithms and data structures will be implemented from scratch instead of relying on existing graphics engines.

The repository serves as a place to experiment with:

- Mathematical foundations of graphics
- Algorithms and data structures
- Memory management and cache efficiency
- Parallelism and concurrency
- Performance measurement and optimization
